# EXP1 – Virtual Workstation

## Aim

To install VirtualBox/VMware or an equivalent open-source cloud workstation with different flavours of Linux or Windows OS on Windows 8 and above.

## Procedure

1. Open the VirtualBox website and download the VirtualBox setup file for Windows.
2. Run the downloaded VirtualBox executable.
3. Follow the installation wizard, select the installation folder, and complete the installation.
4. Click **Finish** to open VirtualBox.
5. In VirtualBox, click **New** to create a virtual machine.
6. Enter a suitable name for the virtual machine and keep the default installation path.
7. Select the ISO image of the operating system to be installed.
8. Select the appropriate operating system type, version, and architecture.
9. Allocate the required memory and processor resources to the virtual machine.
10. Complete the virtual machine configuration and start it.
11. Follow the operating-system installation steps displayed by the virtual machine.
12. Complete the installation and verify that the guest operating system starts successfully.

## Result

Thus, VirtualBox was installed successfully and the virtual workstation was created. The guest operating system was installed and executed successfully.
