# EXP2 – Virtual Machine – C Compiler

## Aim

To install a C compiler in the virtual machine created using VirtualBox/VMware and execute a simple C program.

## Procedure

1. Install VMware Player or VirtualBox and load the CorePlus virtual machine.
2. Power on the virtual machine and open the terminal.
3. Install the C compiler using the following command:

   ```bash
   tce-load -wi compiletc
   ```

4. Wait until the GCC compiler and required libraries are installed.
5. Create a C source file using a text editor and save it with the `.c` extension.
6. Compile the program using the C compiler.
7. Execute the compiled program in the terminal.
8. Verify the output of the program.

## Result

Thus, the C compiler was installed successfully in the virtual machine and the simple C program was compiled and executed successfully.
