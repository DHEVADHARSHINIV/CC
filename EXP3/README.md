# EXP3 – Google App Engine

## Aim

To install Google App Engine and create a Hello World application and other simple web applications using Python/Java.

## Procedure

1. Install the Google App Engine SDK and the required Google Plugin for Eclipse.
2. Open Eclipse and create a new Web Application Project.
3. Enter the project name and configure the Google App Engine SDK.
4. Create the Hello World web application.
5. Configure the application using the required App Engine configuration file.
6. Run the application locally as a Web Application.
7. Open the application in a web browser and verify the output.
8. Create the required Google Cloud/App Engine project and configure the application ID.
9. Deploy the application to Google App Engine.
10. Open the deployed application in a web browser and verify that it is running successfully.

## Result

Thus, Google App Engine was installed successfully and a Hello World web application was created, executed, and deployed successfully.
