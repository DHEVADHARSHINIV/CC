# EXP4 – GAE Launcher

## Aim

To use the Google App Engine (GAE) Launcher to launch web applications.

## Procedure

1. Create a new Google Cloud project or select an existing project.
2. Note the project ID required for the App Engine application.
3. Install and initialize the Google Cloud SDK.
4. Create a project directory for the web application.
5. Create a `www` directory to store the web application files.
6. Create the `index.html` file inside the `www` directory.
7. Create the `app.yaml` configuration file.
8. Configure the application settings and handlers in `app.yaml`.
9. Open the command prompt or terminal in the project directory.
10. Deploy the application using `gcloud app deploy`.
11. Launch the deployed application using `gcloud app browse`.
12. Open the application in the browser and verify that it is working correctly.

## Result

Thus, the Google App Engine Launcher was used successfully to deploy and launch the web application.
