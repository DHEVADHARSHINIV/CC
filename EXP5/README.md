# EXP5 – CloudSim Scheduling

## Aim

To simulate a cloud scenario using CloudSim and run a scheduling algorithm that is not present in CloudSim.

## Procedure

1. Download and install Eclipse for Windows.
2. Download CloudSim 3.0.3 and extract the package.
3. Download Apache Commons Math and extract the required files.
4. Open Eclipse and create a new Java Project.
5. Enter the project name as `CloudSim`.
6. Browse and select the extracted CloudSim source code location.
7. Configure the project libraries by adding the required Apache Commons Math JAR file.
8. Click **Finish** and allow Eclipse to build the CloudSim project.
9. Open the CloudSim examples from the Project Explorer.
10. Select the required CloudSim example/program.
11. Run the program using **Run → Run** or `Ctrl + F11`.
12. Observe the simulation output displayed in the Eclipse console.

## Result

Thus, the cloud scenario was simulated successfully using CloudSim in the Eclipse environment.
