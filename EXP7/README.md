# EXP7 – Hadoop Single Node Cluster

## Aim

To install a Hadoop single-node cluster and run a simple application such as WordCount.

## Procedure

1. Analyze the input file content.
2. Develop the MapReduce program by writing:
   - Map function
   - Reduce function
   - Driver class
3. Compile the source code.
4. Create the JAR file containing the compiled classes.
5. Start the Hadoop Distributed File System (DFS).
6. Create an input directory in HDFS.
7. Copy the input file into the HDFS input directory.
8. Execute the WordCount MapReduce program.
9. Verify the output generated by the program.
10. View the output through the Hadoop Web UI if required.
11. Delete the output directory after verification.

## Result

Thus, the Hadoop single-node cluster was configured successfully and the WordCount MapReduce program was executed successfully to count the occurrences of words in the input file.
