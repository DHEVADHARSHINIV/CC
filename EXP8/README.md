# EXP8 – Creating and Executing Your First Container Using Docker

## Aim

To create and execute the first container using Docker.

## Procedure

1. Install Docker on the system.
2. Verify the Docker installation by running `sudo docker run hello-world`.
3. Create a project directory for the Docker application.
4. Create a Python file named `main.py` and write a simple Python program.
5. Create a file named `Dockerfile`.
6. Specify the Python base image in the Dockerfile.
7. Copy `main.py` into the Docker image.
8. Specify the command to execute the Python program.
9. Build the Docker image using `docker build -t python-test .`.
10. Run the Docker container using `docker run python-test`.
11. Verify the output displayed by the container.

## Result

Thus, the first Docker container was created and executed successfully.
