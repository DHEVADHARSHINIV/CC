# EXP9 – Run a Container from Docker Hub

## Aim

To run a container from Docker Hub.

## Procedure

1. Install Docker and open the terminal.
2. Verify the Docker installation using `docker -h`.
3. Pull the required Docker image from Docker Hub.
4. Run the Ubuntu container using `docker container run -it ubuntu top`.
5. Verify that the container is running using `docker container ls`.
6. Observe the running container and its processes.
7. Stop the container using `docker container stop <container-id>`.
8. Verify that the container has been stopped successfully.

## Result

Thus, a container was successfully pulled from Docker Hub and executed successfully.
